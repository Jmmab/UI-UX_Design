## What I've Learned
- Figma Basics: basic tools, navigation, shortcuts, etc;
- How to make Wireframes (_Lo-Fi_ and _Hi-Fi_);
- How to share your work with clients/collaborators;
- Moodboarding;
- How to deal with images and icons;
- How make basic vector manipulation within Figma;
- <u>Some Features</u>:
    - Masking and Cropping;
    - Object Editing Mode;
    - Boolean Operations;
    - Constraints;
    - Tidy-Up and Smart Selection;
    - Auto-Layout; </br>
    _and much more_.
- All the essentials about Prototyping and Animation;
- How to properly set up Grids for all screen sizes;
- How to create color (and other types of) variables;
- How to use Auto-Layout and other tools to make responsive designs;
- How to use Components to make well-organized and re-usable styles and assets;
- How to properly organize a project, good general UI/UX and Design practices and a dip into commonly used Industry standards for layout, sizing, etc.
